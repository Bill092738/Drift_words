# M6/M7 Live Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing M6 source search and M7 sidebar writing pipelines live, persistent, non-blocking, and fully testable without a model provider.

**Architecture:** Fold the separate source package into the main backend, add pure source/entry admission, then inject provider-independent pipeline functions into the serialized session actor. The server defaults to deterministic template entries, enables real Wikipedia/OpenAlex search only with `DRIFT_SOURCES=1`, and keeps all network/model work outside the actor loop behind bounded background resources.

**Tech Stack:** Haskell/GHC 9.10.3, STM/async, SQLite event log, http-client, Servant/WebSockets, React 19, TypeScript, Zustand, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-24-m6-m7-live-design.md`

## Global Constraints

- No usable model provider exists in this work; Gemini is being integrated elsewhere.
- No real model or search API call may run in CI.
- Without `DRIFT_CONFIG`, branches use the existing mock and writing uses deterministic template entries.
- Without `DRIFT_SOURCES=1`, no source HTTP request may occur.
- An explicit `DRIFT_WRITING=0` disables entries for legacy deterministic tests.
- Only the serialized actor allocates `SourceId` and `EntryId`, persists events, and broadcasts them.
- Source and writing work must never delay pick, backtrack, or branch-ring processing.
- Source searches and their pending queue are bounded; queue overflow skips that edge's search, emits a warning, and still writes its entry.
- Citations may reference only sources attached to the same node/edge.
- API keys must not appear in startup or exception logs.
- Crossref, arXiv, model relevance, Gemini quality, Chinese retrieval, and M8 are out of scope.

## Review Focus

- A permanently blocked source search must not delay exploration or template entry creation; covered in Task 4 actor tests.
- Source arrival before writer snapshot, between snapshot and commit, and after entry commit must converge to identical citations; covered in Task 4 actor tests.
- Out-of-order worker completion and restart must not duplicate IDs, sources, or entries; covered in Tasks 2–4.
- Queue overflow and ordinary source failure must preserve entry generation and actor health; covered in Task 4.
- `api_key` in an HTTP exception/query string must be redacted; covered in Task 1.
